# 这个站怎么用

## 一分钟版

1. 打开文件夹 `D:\奇怪小问题\notes-site`
2. 改 `docs\notes\` 里的 `.md` 文件（用 VS Code 打开，双击就能改）
3. 回到 `notes-site` 文件夹，**双击 `发布.bat`**
4. 黑窗口跑完会自己打开浏览器，看到新内容就成了

就这三件事，没有第四件。

## 为什么非要"发布"一下

网上的站和你电脑上的文件夹是**两份拷贝**：

- 你改的是电脑上那份；
- `https://linkcuty.github.io` 访问的是 GitHub 上那份。

改完不发布，线上就不会变。`发布.bat` 干的就是把电脑上这份同步到 GitHub，GitHub 收到后大约一分钟重新生成网页。

## 发布会做什么

```
  笔记站 · 发布
  -------------------------------
  改动：
     M docs/notes/latex.md

  [1/3] 构建自检 ...
        OK
  [2/3] 提交 ...
        更新笔记 2026-11-01 16:45
  [3/3] 推送到 GitHub ...
        OK

  约 1 分钟后上线：https://linkcuty.github.io/
```

第一步是**构建自检**：Markdown 写坏了（代码块没闭合、链接错位）这里就会报错停下，线上保持上一个好版本。所以放心点，点不坏。

## 发一篇新笔记

1. 在 `docs/notes/` 里复制一份 `csapp-add.md`，改名成你的文件名（**用英文字母和短横线，别带空格**）
2. 把 `# 标题` 和正文换成你的内容
3. 打开 `docs/.vitepress/config.mts`，在 `sidebar` 里照着抄一行：

```ts
{ text: '你的标题', link: '/notes/你的文件名' }
```

4. 双击 `发布.bat`

## 想在本地先看看效果

双击 `预览.bat`：起一个本地服务，几秒后自动打开浏览器，**改完文件自动刷新**，不用发布也能看排版。看完直接关掉黑窗口。

## 出问题了

| 现象 | 原因 |
| --- | --- |
| 黑窗口一闪就没 | 出错了，窗口里有红字，拍照发我 |
| 窗口说"没有改动" | 你还没保存文件，或者改的不是 `docs/` 里的东西 |
| 发布成功但网站没变 | 等一分钟；还不变就去仓库的 Actions 看有没有跑完 |
| 改坏了想退回去 | 告诉我，一条命令的事 |
